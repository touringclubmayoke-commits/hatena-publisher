# ChatGPT → X Card Validator Helper v1.2.0

公開したブログ記事をChatGPTの通常チャットでチェックした後、1回のクリックでX Card Validatorへ渡すためのChrome拡張（Manifest V3）です。

## 1. インストール（初回のみ）

1. `XCardChatGPTHelper.zip` を解凍する。
2. Chromeのアドレスバーで `chrome://extensions/` を開く。
3. 右上の「デベロッパーモード」をONにする。
4. 「パッケージ化されていない拡張機能を読み込む」を押す。
5. 解凍した **XCardChatGPTHelper** フォルダ（`manifest.json` が直下にあるフォルダ）を選択する。
6. 必要に応じて拡張をChromeのツールバーにピン留めする。

## 2. 日常の運用

- 従来どおり、ChatGPTの通常チャットに記事URLを貼って内容をチェックする。
- 問題がなければChatGPTが次の形式の **起動リンク** を作成する。

  `https://cards-dev.x.com/validator#xcard_url=<URLエンコードした記事URL>`

- 起動リンクをクリックする。拡張がそのリンクの `#xcard_url=` を読み取り、X Card Validatorの画面が利用可能なら記事URLの入力と検証ボタンのクリックを試みる。
- **「Preview card」クリック後、ログの `Page fetched successfully` と `Card loaded successfully` を両方検知したら直ちにValidatorタブを閉じる**（固定15秒待機なし）。
- 実行ボタンが見つからない・入力欄が見つからない・エラー・成功ログを確認できない場合などは、タブを閉じない。
- 成功ログが90秒以内に検出できなければ自動クローズはせず、画面を残して原因を確認できるようにする。
- **成功ログはValidatorでの取得・カード読み込み完了の目安であり、X側のキャッシュ強制更新の保証ではありません。**

### ChatGPTへの指示文の例

> 次の記事を公開後チェックしてください。本文・リンク・スマートフォン表示・OGPを確認し、重大な問題がなければ、最後にX Card Helper用の起動リンクを1つ付けてください。起動リンクの形式は `https://cards-dev.x.com/validator#xcard_url=` に記事URLを `encodeURIComponent` した文字列を付けたものです。X側の再取得が成功したと断定しないでください。

## 3. 代替：ポップアップからの起動

Xのログイン遷移などで自動起動がうまくいかない場合は、Chromeのツールバーの **X Card Helper** を開き、ブログURLを貼って「Validatorで開く」を押してください。前回のブログURLはポップアップ内に保存されます。

## 4. 権限・動作・制限

- `storage`: 保留中のURLをChromeのブラウザセッション中に保存。最後のURL・実行結果だけを拡張のローカル領域に保存。
- `webNavigation`: **X Card Validatorへのナビゲーションのみ**を監視し、ログインリダイレクト前に `#xcard_url=` を受け取る。ブラウザ全体の履歴を収集しない。
- `https://cards-dev.x.com/*`: Validatorに表示される入力欄・実行ボタンを探して操作する。
- ChatGPTの会話内容へのアクセス権限は要求せず、外部サーバーへの解析データ送信も行わない（XのValidatorページへの通常のアクセスは発生する）。
- ログイン、CAPTCHA、セキュリティ確認は自動突破しない。
- X側でURL入力欄や検証ボタンが存在しない場合、入力欄を見つけられない／URL入力だけ完了したと表示する。
- X Card Validatorのプレビュー機能は2022年に廃止されたと報告され、2026年9月時点でも旧Validatorが利用できないという報告がある。**本拡張はX側のキャッシュを更新するAPIを持たず、更新を保証しない。**
- Xの実画面（ログイン後のDOM）を本環境から確認できないため、入力欄・ボタンの判定ロジックは汎用実装。対象画面によっては調整が必要。

## 5. よくある質問

**クリックしても何も起こらない**：`chrome://extensions/` で拡張が有効か確認。拡張のポップアップからURLを入れる方法を試す。

**Xのログイン画面になる**：通常のブラウザ操作でログインし、Validatorの画面に戻る。拡張はセッション中に記事URLを保持する（最大30分、ブラウザ再起動で破棄）。

**「入力欄を検出できません」**：X側の仕様変更、機能停止、権限制限の可能性。公開記事のOGP検証とX側の再取得は別機能であることに注意。

**拡張の更新（Chrome/Edge）**：最新版ZIPを解凍して、以前と同じ拡張フォルダの中身を置き換える。その後、`chrome://extensions/` または `edge://extensions/` の該当拡張で **再読み込み** を押す。別の場所で新しく「展開して読み込み」すると、旧版と新版の2つが登録される場合があるため避ける。

## 6. 動作確認の範囲

この配布物についてManifest V3の構成・JavaScript構文、引き継ぎ・URL制限のロジック、ならびに模擬HTMLフォームでの入力欄判定・ボタン判定・値設定をテスト済みです。Chrome/Edgeでの実サイト動作・X側の再取得成功は本環境では未確認です。ログに応じたタブ自動クローズは模擬Validatorで検証しています。実際のX側での完了ログに対する動作は利用者環境で確認が必要です。
